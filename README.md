# 콜레스테롤 대사 시뮬레이터

지단백을 "트럭", 혈관을 "도로", 간을 "물류센터"에 비유해 콜레스테롤 대사를 시뮬레이션하는 교육용 웹 페이지입니다. 정상 상태, 식사, 포화지방, 대사 이상, 이상지질혈증 환자에서 LDL-C·TG·HDL-C가 왜, 얼마나 바뀌는지 보고, 약물이 어디서 어떻게 작용하는지 확인할 수 있습니다.

**바로 열기:** https://sihuny227-rgb.github.io/cholesterol-simulator/

설치 없이 `index.html`을 브라우저로 열어도 됩니다.

## 들어 있는 것

**시나리오 10가지**

| 묶음 | 시나리오 |
|---|---|
| 생리 · 식사 | 정상 상태 · 식사 후 · 포화지방 과다 |
| 콜레스테롤 대사 이상 | 비만·인슐린 저항성 · 폐경 · 갑상선기능저하증 |
| 이상지질혈증 환자 (상담 예시) | A 고LDL혈증 · B 혼합형 · C 고중성지방혈증(TG 1,200) · D 심근경색 후 이차예방 |

**치료 7가지와 작용 지점**

| 번호 | 치료 | 작용 지점 |
|---|---|---|
| ① | 스타틴 (중강도·고강도) | 간 · HMG-CoA 환원효소 |
| ② | 에제티미브 | 소장 · NPC1L1 |
| ③ | PCSK9 항체 | 혈액 · PCSK9 단백질 |
| ④ | 인클리시란 | 간 · PCSK9 mRNA |
| ⑤ | 벰페도산 | 간 · ATP-citrate lyase |
| ⑥ | 피브레이트 | 간 핵 PPAR-α → 모세혈관 LPL |
| ⑦ | 체중감량 (생활요법·GLP-1 RA) | 지방조직 · 내장지방 |

**화면 구성**

- 지단백 물류 지도: 간·소장·지방·말초 조직·동맥 내막 사이를 킬로미크론, VLDL, IDL, LDL, HDL 입자가 돕니다.
- 혈중 지질 계기판: LDL-C, non-HDL-C, apoB, HDL-C, TG를 같은 식사를 한 정상 기준과 비교하고, 환자별 치료 목표 도달 여부를 보여 줍니다.
- 약물 작용 지점 도식: 약을 켜면 막는 지점(✕)과 강화하는 지점이 표시되고, 기전·가이드 효과 수치·대표 약물·주의사항과 4주 뒤 예상 수치를 보여 줍니다.
- 시간에 따른 변화 그래프, 간·대사 조절 계기, 생리 다이얼.

## 모델

간 콜레스테롤 풀과 SREBP-2 되먹임, LDL 수용체·PCSK9, LPL 포화, CETP 교환을 단순한 미분방정식으로 묶고, 가이드의 경향을 재현하도록 계수를 맞췄습니다. 하루 세 끼 일반식을 먹는 상태(LDL-C 100)를 정상 기준으로 씁니다.

| 상황 | 모델 결과 |
|---|---|
| 포화지방 식단 | LDL-C 약 +21% |
| 비만·인슐린 저항성 | TG 약 260, HDL-C 34, apoB 123 |
| 갑상선기능저하증 | LDL-C 약 +50% |
| 스타틴 중강도 / 고강도 | LDL-C −31% / −50% |
| 에제티미브 | LDL-C 약 −21% |
| PCSK9 항체 / 인클리시란 | LDL-C 약 −47% / −46% |
| 벰페도산 | LDL-C 약 −23% |

> **교육용 개념 모델입니다.** 수치는 경향을 보여 주기 위한 근사치이며, 개별 환자의 수치 예측이나 처방 판단에 쓰면 안 됩니다.

## 파일 구조

```
index.html     빌드된 페이지 (이 파일 하나로 동작)
build.js       src/ 를 합쳐 index.html 을 만드는 스크립트
src/model.js   지단백·콜레스테롤 구획 모델
src/app.js     지도 애니메이션, 그래프, 화면 동작
src/page.html  화면 구조와 스타일
```

`src/`를 고친 뒤 다시 만들려면 Node.js로 실행합니다.

```bash
node build.js
```
